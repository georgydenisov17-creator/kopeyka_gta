# 🚗 Симулятор Копейки — Top-Down Edition

Аркадная 2D-игра с видом сверху в стиле первой GTA на чистом **Canvas 2D** (без 3D и WebGL).

## 📁 Структура проекта

```text
kopeika-topdown/
├── index.html   # Разметка экрана игры, HUD, меню, гаража и настроек
├── style.css    # Стили интерфейса, HUD, карточка управления и экранов
├── game.js      # Генерация мира 10×10 кварталов, физика машины, NPC, звук и рендер
└── README.md    # Описание проекта и структура файлов
```

## 🎮 Управление

* **W / ↑** — газ
* **S / ↓** — тормоз / задний ход
* **A / D / ← / →** — поворот
* **Space** — ручной тормоз (дрифт)
* **Shift** — нитро
* **Esc** — выход в меню / пауза

## 🚀 Запуск

Откройте `index.html` в любом современном браузере или запустите локальный статический сервер (например, `python -m http.server 8000` из папки проекта).
